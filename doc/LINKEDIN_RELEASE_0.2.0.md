# LinkedIn release — Oxide 0.2.0

Oxide 0.2.0 is out — a fast, polyfunctional dual-panel file manager for the terminal, in the spirit of Midnight Commander but built for today, written in Rust and aimed at Linux and macOS, with a real subshell when you need one. Stability is the main aim of this release: it ships many critical fixes across panels, archives, subshell, and dialogs, together with features worth trying — preview images right in the terminal with F3 (Kitty, iTerm2, Sixel, half-blocks), an F1 Actions menu you can actually navigate with the keyboard, and a safety cue you do not get everywhere: when anything running in the subshell is root — including after `sudo -s` — the bottom menu bar turns red, even if Oxide itself still runs as your normal user. It is also Raspberry Pi 5 friendly — prebuilt aarch64 binary in install/aarch64.

If you live in the terminal, it is worth a look. Prebuilt binaries and source are on GitHub: https://github.com/buchslava/oxide — full release notes: https://github.com/buchslava/oxide/blob/main/CHANGELOG.md#020---2026-05-09
