# LinkedIn — compare two files (Ctrl+X D)

## Facts about Oxide

In practice you compare files **in the same folder all the time** — `config` vs `config.bak`, two builds, a tweak you’re unsure about. Most twin-panel managers still want **left vs right**, one file per panel.

**Oxide** lets you **mark two files** (**Space**) — even **both in one panel** — hit **Ctrl+X D**, and get a **full-screen side-by-side diff**. No shuffling paths between panels, no external `diff` command. Pick any two, compare, done.

That same-panel trick is the bit other managers usually skip. Oxide doesn’t.
