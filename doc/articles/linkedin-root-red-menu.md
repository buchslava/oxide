# LinkedIn — root subshell, red bottom menu

## Facts about Oxide

Most terminal file managers won’t warn you when the subshell turns into root. **Oxide does** — and that’s deliberate: a **red bottom menu** so you don’t mistake a root session for everyday routine. Safety you don’t get elsewhere.
